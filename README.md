# EduPath 📚

Hey! Welcome to EduPath - a website I built to help students find their way through the confusing world of education. Whether you're struggling with exam prep, looking for scholarships, or trying to figure out what to do after graduation, I've got you covered.

## What's This About?

I created this platform because I noticed how overwhelming education can be. There's so much information out there, but it's scattered everywhere. So I thought, why not bring it all together in one simple place?

## What You'll Find Here

- **Blog Posts** - I write about stuff that actually matters to students:
  - Tips on how to study without burning out
  - Real advice on preparing for exams
  - How to write a killer Statement of Purpose
  - Finding and applying for scholarships (yes, free money!)
  - Career guidance for when you're about to graduate and panicking
  
- **Resources** - Helpful tools and links I've collected
- **Contact** - Got questions? Just reach out

## Tech Stack

Nothing fancy, just the basics done right:
- HTML5
- CSS3
- Vanilla JavaScript
- SVG graphics

I wanted to keep it simple and fast. No heavy frameworks, no complicated build processes.

## Running It Locally

Want to check it out on your machine? Here's how:

```bash
# Clone it
git clone https://github.com/YOUR_USERNAME/edupath.git
cd edupath

# Start a local server
python3 -m http.server 8000

# Open http://localhost:8000 in your browser
```

That's it. Simple.
